# PLM 物料校验提示清单（台账）

> 版本 v1.0 ｜ 2026-11-10
> 用途：登记 PLM 录入助手全部校验提示的**文案、级别、触发条件、显示位置、是否阻断、调整入口**。
> 维护约定：**新增或调整任何提示，都必须同步更新本表**，避免"提示改了、文档没跟上"。

---

## 一、级别定义

| 级别 | 前端表现 | 是否阻断保存 | 典型场景 |
|---|---|---|---|
| **error** | 红色 `✕` + 文案；「保存并回填」置灰 | **是**（只能改或取消） | 名称过短、名称与分类明显不符、重复规格 |
| **warn** | 黄色 `!` + 文案；可继续保存 | 否 | 空格、乘号、括号、名称含型号 |
| **pass** | 绿色 `✓ 名称与规格符合录入规则` | — | 无任何问题 |
| **skip** | 顶部信息条灰字 | 否 | 未取编码、分类未命中，查重被跳过 |

规则：**有任一 error → 保存按钮禁用**，点击会弹框提示；warn 不阻断。

## 三、分类一致性（名称 ↔ 小类）

| 项 | 说明 |
|---|---|
| 判定来源 | 编码前 6 位 → 小类 |
| 相似度算法 | 名称与各小类标准名的二元组 Dice 相似度 |
| 判定条件 | ① 与当前小类相似度 < `minCurrent`(0.4)；② 与其它小类最高 ≥ `minBest`(0.6)；③ 差值 ≥ `minGap`(0.25) |
| 级别 | 命中且 `score ≥ blockBest`(0.9) → **error**；否则按 `level`(默认 warn) |
| **前缀命中（2026-11-10 新增）** | 名称以其它小类标准名开头（长度 ≥ 2）时直接判定，解决「端子标记号」这类短标准名被 Dice 稀释而漏判 |
| 保护 | 当前小类名本身是前缀时不判，避免误伤 |
| 调整入口 | `material-rules.json` → `name.subMismatch`（`enabled/level/blockBest/minCurrent/minBest/minGap`）；算法在 `material-rules.js` `detectSubMismatch` |

**已知案例**

| 名称 | 所选小类 | 结果 |
|---|---|---|
| 端子标记号 | 100101 固定式框架断路器 | error（更像 101601 端子）✓ 修复后 |
| 端子 | 100101 | error |
| 断路器 / 空气开关 / 微型断路器 | 对应正确小类 | 无提示 ✓ |
| 热缩管 | 100101 | error |

## 四、规格类提示

### 阻断（error）

| 编号 | 提示文案 | 触发条件 | 位置 | 调整入口 |
|---|---|---|---|---|
| S1 | 型号规格不能为空 | 规格为空 | 规格下 | `material-rules.js` `checkSpec` |
| S2 | 型号规格过短（至少 2 个字符） | 长度 < `spec.minLen` | 规格下 | `spec.minLen` |
| S3 | 型号规格过长（最多 64 个字符） | 长度 > `spec.maxLen` | 规格下 | `spec.maxLen` |
| S4 | 请使用半角字符（全角字母/数字/标点会导致同物不同码） | `spec.halfWidthOnly` 且含全角 | 规格下 | `spec.halfWidthMsg` |
| S5 | 规格必须包含字母或数字，不能只写中文或符号 | `spec.requireAlnum` | 规格下 | `spec.requireAlnumMsg` |
| S6 | 规格里不要写项目号 / 产号 / 制造令号 | 命中 `spec.forbidPatterns` | 规格下 | 各 `msg` |
| S7 | 规格不能写“待定”这类占位内容，必须能唯一确定实物 | 命中 `spec.forbidWords` | 规格下 | `spec.forbidWordMsg` |

### 提示（warn）

| 编号 | 提示文案 | 触发条件 | 位置 | 调整入口 |
|---|---|---|---|---|
| S8 | 乘号统一用 *（如 6*80、3*25+1*16），不要用 × / x | 数字之间出现 x/X/× | 规格下 | `spec.multiplyMsg`、`spec.multiplyChars` |
| S9 | 括号请使用半角 () | 含全角括号 | 规格下 | 代码内固定文案 |
| S10 | 规格首尾有多余空格，建议去除 | 首尾空格 | 规格下 | 代码内固定文案 |
| S11 | 规格里有连续空格，请用单个空格分隔参数 | 连续空格 | 规格下 | 代码内固定文案 |
| S12 | 规范写法：IC65N C10A/2P | 归一化后与原文不同 | 规格下（可点击应用） | `suggestSpec()` |
| S13 | 该小类的关键参数一个都没识别到（型号/极数/…），请按“参数+数值”补全… | 命中参数数为 0 | 规格下 | `spec.requireParamMsg`、`requireParamHit` |
| S14 | 同小类已有完全相同规格：`10010100271 断路器 IC65N C10A/2P` | exact/sep 级重复 | 规格下（红字） | 前端 `renderTips` + `fplm-server` 的 `duplicates` |

> **S8 的边界**：只把「数字之间的 x/X/×」当乘号，型号里的 X（NXB-63、NSX100F、CJX4）不报，避免误伤。

## 五、编码与降级提示

| 编号 | 提示文案 | 级别 | 触发条件 | 位置 |
|---|---|---|---|---|
| C1 | 物料编码：（未申请） | 信息 | 未走编码器 | 弹窗顶部信息条 |

## 六、前端呈现规则（需要改归类时看这里）

| 规则 | 实现 |
|---|---|
| 名称侧判定 | 含「名称/品名」，或「小类/分类」+「不匹配/不符/选错/更像」 |
| 规格侧 | 其余全部（含「该小类的关键参数…」） |
| 图标 | error `✕` 红；warn `!` 黄；通过 `✓` 绿 |
| 阻断 | `errors.length > 0` → 「保存并回填」`disabled` |
| 重复合成 | 前端把 exact/sep 重复**合成一条 error**，与重复明细一起显示 |
| 调整位置 | `ItemSmartInput.js` → `isNameMsg()` / `renderTips()` |

## 七、调整指引（改哪里）

| 想改什么 | 改哪里 | 是否重启 |
|---|---|---|
| 提示文案 | `src/config/material-rules.json` 对应 `*Msg` | 否（按 mtime 热加载） |

## 八、待调整事项（后期重点）

| # | 事项 | 现状 | 可选方向 |
|---|---|---|---|
