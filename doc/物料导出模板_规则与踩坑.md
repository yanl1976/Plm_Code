# 物料导出模板 — 规则、规范、要点与踩坑记录

> 目的：把系统全部物料按小类导出为可分发的「特征参数填写模板」，供团队补全各参数具体值。
> 风格参照：`doc/390403001电源类.xlsx`（横向表头 + 逐物料填值）。
> 产出位置：`doc/物料导出模板/`（209 个小类文件，含 10 个暂无物料的空模板；物料 sheet 约 22450 个）。

---

## 一、数据源与字段映射

| 文件 | 用途 |
|---|---|
| `data/materials.ndjson` | 原始物料主数据（约 22459 条）。按 `SUBPREFIX`（=小类编码）或 `FNUMBER` 前 6 位归属小类 |
| `data/extract-baseline.json` | AI 提取的结构化特征参数值，键为 `items[物料号]` |
| `src/config/feature-templates.json` | 编码体系（大类→中类→小类）与每个小类的特征参数模板 |

### 原始字段 → 导出列映射

| 导出列 | 原始字段 | 说明 |
|---|---|---|
| 物料编码 | `FNUMBER` | 物料唯一号（11 位），也用作 sheet 名 |
| 物料名称 | `FNAME` | |
| 规格型号 | `FSPECIFICATION` | 注意：**列名必须是"规格型号"，不是"图号(型号)"** |
| 主要参数 | `F_ZXCV_ZYCS` | 专用参数，覆盖率约 66% |
| 技术参数 | `F_ZXCV_JSCS` | 覆盖率仅约 2.5%，多数留空待补 |
| 单位 | `UNITNAME` | 如「台」「米」；**必须放在最末列** |
| 厂家 | `F_ZXCV_GYS` | 当前基本全空 |
| 特征参数（型号/额定电压/额定电流/极数/脱扣器/分断等级/分断能力/脱扣曲线/订货号/其它） | `extract-baseline.json → items[物料号][参数名]` | 缺失则留空待完善 |
| 小类归属 | `SUBPREFIX` 或 `FNUMBER` 前 6 位 | 用于分组与文件命名 |

> 小类特征参数列表取自 `feature-templates.json`：优先用该小类 `subParams[小类code]`，否则继承中类 `params`。不同中类的参数列不同，导出时随之变化。

## 二、导出格式规范（最终确认版）

每个 xlsx 文件 = **一个小类**：

1. **Sheet 1：`汇总明细`**（导航用）
   - 列：物料编码、物料名称、规格型号、主要参数、技术参数、单位
2. **其余 Sheet**：**每个物料一个**，sheet 名 = 物料编码（11 位，≤31 字符，合法）
3. **物料 Sheet 表头（横向，单行数据）**：
   ```
   物料编码 | 物料名称 | 规格型号 | 主要参数 | 技术参数
   | 型号 | 额定电压 | 额定电流 | 极数 | 脱扣器 | 分断等级 | 分断能力 | 脱扣曲线 | 订货号 | 其它
   | 厂家 | 单位
   ```
   - `型号` 保留为**独立列**（不并入"规格型号"）。
   - 已**剔除**：物料组号、小组单位、物料小组号（判定无用）。
   - **单位列必须在最末**。

### 文件命名
- 文件名 = `小类编码 + 小类名称 + .xlsx`，例：`100101固定式框架断路器.xlsx`
- 需过滤文件名非法字符：`\ / : * ? " < > |` 及换行，替换为 `_`。

## 三、如何重新生成

生成脚本须为 **`.cjs`**（项目 `package.json` 是 ESM，`.js` 内不能用 `require`），并放在**项目根目录**才能解析 `node_modules/xlsx`。

流程：
1. 读 `src/config/feature-templates.json`，遍历 中类→小类，取该小类 params（`subParams` 优先，否则 `params`）。
2. 读 `data/materials.ndjson`，按小类编码分组。
3. 读 `data/extract-baseline.json` 取 `items`（特征参数值）。
4. 逐小类生成文件写入 `doc/物料导出模板/`（先建文件夹 `recursive`）。
5. 无物料的小类生成仅含「汇总明细」表头的空模板（保留作填写模板）。

依赖：`npm install xlsx --no-save`（已装）。

## 四、踩坑记录（重要，后期避免重犯）

1. **列名被擅改**：原要求"规格型号"，初版误用参考表里的"图号(型号)"。→ 必须用"规格型号"。
2. **无用通用列**：初版照搬参考表的"物料组号 / 小组单位 / 物料小组号"三列，用户判定无用 → **必须剔除**。
3. **单位列位置**：单位必须放**最末**，不能插在通用列之后。
4. **一物料一 sheet，不是一小类一 sheet**：用户明确要求"一个物料一个 sheet"；参考表虽是「一小类一个 sheet 多行」，但本需求是逐物料分 sheet。两者要分清。
5. **擅自加列 / 分段**：曾自作主张加 供应商、生产厂商、图号、备注，以及把内容拆成"原始信息 / 后期完善"两段式分区。用户未要求，**一律删除**；其中"物料编码"经确认后保留（用户曾要求、一度列入未要求、最终确认需保留）。
6. **特征参数必须保留为表头列**：不能收进"第二部分"区块；应作为列保留（空白待完善），团队在其基础上继续填值。
7. **数据源必须用原始物料**：必须用 `materials.ndjson` 原始信息，不能只用 AI 提取结果；特征参数值取自 `extract-baseline.json`，缺失留空。
8. **Excel 占用导致写入失败**：覆盖正在被 Excel 打开的文件会报 `EBUSY: resource busy or locked`。生成前先关闭目标文件，或脚本 `try/catch` 后改名输出。
9. **运行环境**：`package.json` 为 ESM，普通 `.js` 不能用 `require('xlsx')`；脚本须用 `.cjs` 且放在项目根（才能解析 `node_modules/xlsx`）。
10. **空小类**：209 小类中有 10 个在 `materials.ndjson` 暂无物料，会生成空模板（仅汇总表头）。属正常，保留即可。

## 五、待办 / 可优化
- 10 个空小类是否保留模板，或剔除（待用户确认）。
- 若 `materials.ndjson` 的 `F_ZXCV_GYS`(厂家) 后续有数据，导出自动带上；目前全空。
- 若后期在①页增删某小类参数，重跑导出脚本即可刷新全部模板。
