## 一、国标命名规则

依据 **GB/T 12706 / GB/T 5023 / GB/T 5013 / GB/T 9330 / GB/T 9331 / GB/T 13033**，
电缆型号由固定顺序的代号组成：

```
系列代号 + 导体 + 绝缘 + 护套 + 特征 + 额定电压 + 芯数×截面 + 标准号
```

示例：`YJV22-0.6/1kV 3×150+1×70`

| 段 | 代号含义 |
|---|---|
| 导体 | `T` 铜（可省略）、`L` 铝、`TR` 软铜 |
| 绝缘/护套 | `V` 聚氯乙烯、`YJ` 交联聚乙烯、`E` 乙丙橡胶、`F` 氟塑料 |
| 用途 | `B` 布电线、`K` 控制、`R` 软线、`DJ` 计算机 |
| 特征 | `ZR` 阻燃、`NH` 耐火、`WDZ` 低烟无卤、`ZA/ZB/ZC` 阻燃等级 |
| 铠装 | `22` 钢带、`32` 细钢丝 |

### 1.1 重要澄清

**国标不要求在「规格型号」字段中写入标准号。**

- `GB/T 12706` 等是**产品标准**，规定结构、材料、性能、试验方法
- 标准号出现在采购合同、技术协议、设计图纸，而非规格型号
- 型号代号（`YJV`/`KVV`/`YCW`）本身已隐含执行标准

> 现有 1,193 条规格中 0 条写标准号 —— **属于正常，不是数据缺失**。

## 四、问题分类与处理手段

| 问题类型 | 典型例子 | 规模 | 处理手段 | 优先级 |
|---|---|---|---:|---|---|
| **名称分叉** | 电缆 / 控制电缆 / 电力电缆 | 391 条细分名 | 名称归一 + 规格承载信息 | **P1（当前）** |
| 规格写法不一 | `mm^2`/`m㎡`；`500V` | 33 + 398 条 | 规则校验 + 导入转换 | P2 |
| 非国标/特殊 | IEEE 45、WTTC | 316 条 | 人工确认，不强行归类 | P3 |
| 说明为空 | `FDESCRIPTION` 全空 | 1,193 条 | 代码表自动填充 | P2 |

### 关键判断

**「控制电缆 ↔ 电缆」不属于同义词，属于子类与上位词的关系。**

- 同义词：空气开关 ↔ 断路器（同一物，两个叫法）
- 子类：控制电缆 → 电缆（控制电缆是电缆的一种）

**不能简单合并**，否则丢失"控制/船用/耐寒"等有效信息。
正确做法是：**名称统一到上位词，细分信息由规格里的型号代码承载**。

## 六、第 1 步：名称问题（当前聚焦）

### 6.1 核心原则

```
名称 = 实物大类（小类标准名）  →  统一写「电缆」
细分 = 型号代码 + 参数        →  写在规格里
```

例：

| 现状 | 目标 |
|---|---|
| 名称「控制电缆」+ 规格 `ZRKYJVP-500V 5*1.5mm²` | 名称「电缆」+ 规格 `ZRKYJVP-450/750V 5*1.5mm²` |
| 名称「电力电缆」+ 规格 `YJV-8.7/10kV-3*35` | 名称「电缆」+ 规格 `YJV-8.7/10kV-3*35` |
| 名称「船用电缆」+ 规格 `CEPJ/SC 1000V 1*4mm²` | 名称「电缆」+ 规格 `CEPJ 1000V 1*4mm²` |

### 6.2 安全边界

**只有规格里能识别出型号代码时，才允许归一名称。**

| 情况 | 是否可归一 | 原因 |
|---|---|---|
| `控制电缆` + `KYJVP-...` | ✅ | KYJVP 已说明是控制电缆 |
| `控制电缆` + `3*1.5`（裸规格） | ❌ | 归一后"控制"信息丢失 |
| `船用电缆` + `CEPJ-...` | ✅ | CEPJ 是船用电缆型号 |
| `高压电缆` + `YJV-8.7/10kV` | ✅ | 电压等级在规格里 |

### 6.3 执行计划

```
① 导出名称清单（名称 / 条数 / 其中有型号代码的条数）
        ↓
② 业务确认：哪些细分名称可以归一
        ↓
③ 建立同义词映射（bySub 110302：细分名 → 电缆）
        ↓
④ 存量数据处理：
     有代码的 → 建议改名（导出清单，人工执行或 PLM 批量更新）
     无代码的 → 保留细分名称，先补型号
        ↓
⑤ 新物料录入：名称只允许「电缆」（小类标准名优先）
```

### 6.4 预期效果

| 指标 | 现状 | 目标 |
|---|---:|---:|
| 名称为「电缆」 | 802 / 1,193（67%） | ≥ 90% |
| 细分名称 | 391 条 | < 100 条（仅剩无代码的） |
| 名称不统一导致的统计偏差 | 无法按品类统计 | 可按型号代码统计 |
