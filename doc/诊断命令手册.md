## 一、插件侧（PLM 页面 Console）

> 打开任意 PLM 页面，按 F12 → Console，粘贴执行。

### `$1` 环境探测

```js
__plmProbe.env()
```

返回：

```js
{ HoteamUI: true, DataService: true, AsyncCall: true, Call: true,
  ServiceUri: '...', timeoutMs: 180000 }
```

| 字段 | 期望 | 异常含义 |
|---|---|---|
| `HoteamUI` | `true` | `false` = 不在 PLM 框架内（页面不是 PLM 页） |
| `DataService` | `true` | `false` = 平台服务不可用 |
| `AsyncCall` | `true` | `false` 会退回同步调用（慢，可能卡页面） |
| `timeoutMs` | `180000` | 是 60000 说明用的是旧版插件或配置没生效 |

### `$2` 一键自检（最常用）

```js
(function () {
  console.table({
    '主插件已加载': typeof window.ItemSmartInputConfig !== 'undefined',
    '插件对象 __plmSync': typeof window.__plmSync,
    '彩蛋对象 __plmEgg': typeof window.__plmEgg,
    '累计回填次数': window.__plmEgg ? window.__plmEgg.count() : '(无)',
    '服务地址': window.ItemSmartInputConfig ? window.ItemSmartInputConfig.apiBase : '(无)',
    '看板地址': window.ItemSmartInputConfig ? window.ItemSmartInputConfig.inventoryBase : '(无)',
  });
  console.log('已加载的插件脚本：');
  [...document.querySelectorAll('script')]
    .filter(function (s) { return (s.src || '').indexOf('ItemSmartInput') >= 0 })
    .forEach(function (s) { console.log('  ' + s.src.split('/').pop()); });
})()
```

判读：

| 结果 | 结论 |
|---|---|
| 主插件 `true` + 彩蛋 `object` | ✅ 正常 |
| 主插件 `true` + 彩蛋 `undefined` | 彩蛋文件没加载 → 见 `$3` |
| 主插件 `false` | fileref 没生效 / 没回收应用池 |
| 「已加载的插件脚本」为空 | 平台用 XHR+eval 加载（正常，不影响功能） |

### `$3` 彩蛋加载诊断

```js
// 手动验证彩蛋文件是否可访问（绕过动态注入）
var s = document.createElement('script')
s.src = '/InforCenter/Config/ItemSmartInput/Js/ItemSmartInput.easteregg.js'
s.onload = function () { console.log('✅ 文件可访问', typeof window.__plmEgg) }
s.onerror = function () { console.error('❌ 404，文件不存在或路径不对') }
document.head.appendChild(s)
```

| 结果 | 处理 |
|---|---|
| `✅ 文件可访问 object` | 文件在，主插件是旧版（< v1.97）或缺 `easterEggFile` 配置 |
| `❌ 404` | 文件没传 / 路径不是 `/InforCenter/Config/ItemSmartInput/Js/` |

路径不对时，在 `ItemSmartInput.config.js` 里写死：

```js
easterEggFile: '/InforCenter/Config/ItemSmartInput/Js/ItemSmartInput.easteregg.js',
```

### `$5` 单个小类数据量探测（不写快照）

```js
__plmProbe.scan({ subs: ['120102'], concurrency: 1 })
```

输出：

```
[PLM探测] [1/1] 120102 返回 411 行  3200ms
[PLM探测] === 完成：1 个小类，共 411 行，失败 0，总耗时 3200ms ===
```

用途：判断某小类为什么超时（行数多？服务慢？）

### `$6` 分页探测（怀疑返回被截断时）

```js
__plmProbe.pagerTest(['120405'])
```

### `$7` 快照同步

```js
__plmSync.plan()        // 看模式与起点（不实际同步）
__plmSync.start()       // 开始同步（增量或全量，按 plan 的 mode）
__plmSync.start({ force: true })   // 强制全量
__plmSync.status()      // 看进度
__plmSync.failed()      // 看待补跑的小类清单
__plmSync.retry()       // 补跑失败的小类（不加时间条件，全查）
__plmSync.retry(['120408', '120405'])   // 指定小类补跑
__plmSync.clearFailed() // 清空待补跑清单
__plmSync.stop()        // 停止（当前批次结束后生效）
```

`plan()` 返回示例：

```js
{
  ok: true,
  mode: 'incremental',              // incremental = 增量；full = 全量
  afterTicks: 639301752260000000,   // = 0 表示走全量
  lastAt: '2026-11-15T03:53:38.107Z',
  lastCount: 23399,
  subCount: 209,
  prefix: ['10', '11', '12'],
  state: 'Using',
}
```

**判读**：`mode='incremental'` 且 `afterTicks > 0` → 下次同步只拉变化的数据。

### `$8` 自动同步

```js
__plmSync.auto.tick()    // 立即检查一次（不用等 30 分钟）
__plmSync.auto.stop()    // 停掉自动同步
__plmSync.auto.start()   // 重新启用
```

### `$9` 彩蛋（礼花）

```js
__plmEgg.status()        // 累计次数、级别、开关
__plmEgg.count()         // 只读次数（无日志）
__plmEgg.super()         // 强制放一发金色超级大礼花
__plmEgg.preview(1500)   // 按「假设累计 1500 次」预览强度（不改计数）
__plmEgg.test(8)         // 按级别预览
__plmEgg.off()           // 本次会话关闭
__plmEgg.reset()         // 计数清零
```

```bash
cd /opt/Plm_Code

grep -o '"ECODE":"..' data/materials-plm.ndjson | cut -c10-11 | sort | uniq -c | sort -rn
```

## 五、部署后验证

### `$41` 文件指纹核对

```powershell
$base = "D:\PLMSOFT\Server\InforCenter\Config\ItemSmartInput"
Get-ChildItem $base -Recurse -Include *.js,*.fileref | ForEach-Object {
  '{0,-32} {1,8} B  {2}' -f $_.Name, $_.Length, (Get-FileHash $_.FullName -Algorithm SHA256).Hash.Substring(0,16)
}
```

### `$42` fileref 注册行数

```powershell
Select-String -Path "$base\ItemSmartInput.fileref" -Pattern "^\s*<JSFile" | ForEach-Object {
  $_.LineNumber.ToString() + ': ' + $_.Line.Trim()
}
```

| 期望 | 说明 |
|---|---|
| 每个 group 只有 2 行（config + Js/ItemSmartInput.js） | ✅ 正确 |
| 出现 3 行（多一个根目录 ItemSmartInput.js） | ⚠️ 插件会加载两次，删掉多余那行 |
| 出现 easteregg 行 | ⚠️ 会 404 中断加载链，删掉 |

### `$43` 回收应用池

```powershell
Get-IISAppPool | Select-Object Name, State
Restart-WebAppPool -Name "你的PLM应用池名"
```

### `$44` 部署后三件事

```js
__plmProbe.env()          // 版本与超时是否生效
__plmEgg.count()          // 彩蛋是否加载
__plmSync.plan()          // 3100 是否连通、模式是否正确
```

## 七、症状 → 命令 速查

| 症状 | 跑什么 | 判读 |
|---|---|---|
| 没有「智能录入」按钮 | `$2` + 看 Console 有无「探测到抽屉弹窗」 | 有「尚未探测到」= 不在物料新增页 |
| 按钮出现两次 | `$42` | fileref 重复注册 |
| `__plmEgg is not defined` | `$3` | 404 = 文件没传或路径不对 |
| 提示不刷新 | `$2` 后重试操作 | 确认 v1.98+ |
| 查重结果为空 | `$11` | `count=0` = 索引没建 |
| 快照条数不对 | `$12` + `$13` | 对比 PLM 快照与合并快照行数 |
| 同步很快但上报 0 条 | `$7` | `mode=incremental` + 数据无变化 = 正常 |
| 同步很慢 | `$7` | `mode=full` = 走了全量 |
| 某小类总是失败 | `$5` 探测该小类 | 行数多/超时 → 单独 `retry` 或调大 `plmQueryTimeout` |
| 库存显示「—」 | `$21` + `$2` | `erp=false` = 正常降级；标题栏 ERP 红点 |
| 选型规格写法不对 | `$33` | 有缺口就补别名 |
| 弹窗标题版本不对 | `$2` 看脚本是否旧版 | 没回收应用池 |
| 部署后行为没变 | `$41` 对比 SHA | 文件没覆盖成功 |
