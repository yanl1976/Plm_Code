## 二、业务全方位矩阵

### 2.1 类别（小类 6 位）

| 检查项 | 规则 | 数据来源 | 提示 | 阻断 | 开关 |
|---|---|---|---|---|---|
| 小类是否存在 | 必须命中 `classification-map.json` 的 6 位小类 | 分类体系 | 选小类时提示 | 是（提交 400） | — |
| 编码前缀一致 | 物料编码前 6 位 = 所选小类 | PLM 编码 / 待新增清单 | 提示 | 是（编码与小类不一致） | — |
| 名称与小类是否匹配 | `detectSubMismatch` 9 步：小类名/名称主导小类/品类词（≥3 条且 ≥80% 纯度）… | `dedup.js` 生成的 `name-sub-index.json` + 小类词表 | 明确提示「疑似小类选错」 | 是 | `subMismatch` |
| 大类/中类一致性 | 小类 → 中类 → 大类 由映射唯一决定 | 分类体系 | — | 结构上不可能错 | — |

### 2.2 名称

| 检查项 | 规则 | 数据来源 | 提示 | 阻断 | 开关 |
|---|---|---|---|---|---|
| 非空 | 必填 | — | — | 是 | `nameEmpty` |
| 长度 | 2–24 字（`material-rules.name`） | 规则配置 | 超长建议细节写进规格 | 是 | `nameLen` |
| 全角字母/数字 | 名称以中文为主，全角会导致同物不同码、按半角检索不到 | 规则配置 `halfWidthOnly` | 明确指出问题 | 是 | `nameFullWidth` |
| 禁止字符 | `forbidChars`（如 `/ \ : * ? " < > |` 等） | 规则配置 | 指出字符 | 是 | `nameForbidChars` |
| 禁止模式 | `forbidPatterns`（如纯数字、括号说明、项目名等） | 规则配置 | 指出模式 | 是 | `nameForbidPattern` |
| 名称 = 规格 | 归一化后完全相同（去空格/小写） | 规则配置 | 提示「细节写进规格」 | 是 | `nameEqualsSpec` |
| 名称含型号/数字 | `detectNameModel`：名称里出现型号样式或数字 | 规则配置 | 仅提示标准写法，**允许保存** | 否 | — |
| 同义词建议 | global + bySub（小类优先）；exact / contains / prefix 三种匹配 | `name-synonyms.json` | 建议标准名，可一键采用 | 否 | — |
| 命名范式建议 | 小类范式：GB/T 前缀、名称结构、字段占位 | `naming-guide.json` | 展示范式与示例 | 否 | — |
| 名称单元 | `nameUnits`：枪机/球机/半球 → 枪型/球型/半球网络摄像机 | `naming-guide.subs[].nameUnits` | 建议（且参与查重签名） | 否 | — |

### 2.3 规格型号

| 检查项 | 规则 | 数据来源 | 提示 | 阻断 | 开关 |
|---|---|---|---|---|---|
| 非空 | 必填 | — | — | 是 | `specEmpty` |
| 长度 | 2–500 字符（`material-rules.spec`） | 规则配置 | 超长请精简 | 是 | `specLen` |
| 半角 | 全角字母/数字/标点不允许 | 规则配置 `halfWidthOnly` | 「请使用半角字符」 | 是 | `specFullWidth` |
| 含字母或数字 | 纯符号/纯中文不算规格 | 规则配置 `requireAlnum` | 说明原因 | 是 | `specAlnum` |
| 禁止模式 | `forbidPatterns`（如项目名、供应商、图号） | 规则配置 | 指出模式 | 是 | `specForbidPattern` |
| 占位内容 | `forbidWords`（如「待定」「暂无」「TBD」） | 规则配置 | 指出占位词 | 是 | `specPlaceholder` |
| 乘号写法 | 数字之间的 `x/X/×` 建议统一为 `*` | 规则配置 | 仅提示 | 否 | — |
| 强度/单位/符号 | `spec.js` 符号表（`mm^2`、`Φ`、`m^3` 等） | `spec-symbols.json` | 建议规范写法 | 否 | — |
| 结构解析 | `struct-spec`：型号/系列/极数/电流/电压/分断/附件… | `spec-fields.json` | 解析结果用于补全与查重签名 | 否 | — |
| 分段补全 | `spec-complete`：按「当前在填哪一段」给候选（型号/极数/额定电流…） | 物料快照 + `param-standard.json` | 候选（含 ghost 续写） | 否 | — |
| 字段宽度 | GGXH 500（PLM `PSEITEM-CREATE.page` 正则） | PLM 元数据 | 超限告警/保存前拦截 | 是（插件 `strictWidth`） | — |

| 长度 | ZYCS ≤1000（PLM `STRING1000`）；看板提交前后端同拦 | PLM 元数据 + `server.js` | 超限提示并拒绝提交 | 是（>1000） | — |
| 载体宽度 | 保存时经 FLSXHB（`STRING100`）中转，超 100 会截断 | 插件 `zycsMaxLen` / `FLSXHB` 上限 | 截断日志提示 | 否（截断） | — |
| 占位文字保护 | 不覆盖 `ZYCS_PLACEHOLDER` 与已有业务值 | 插件 `isFillable` | 日志说明 | 否 | — |
| 停用/删除系列 | 字典重建后不再提供其配件 | 选型库 `enabled` 状态 | — | 否 | — |
| 预分配编码 | 小类 6 位 + 5 位流水（看板本地计算） | `next-code` / 提交时顺延 | 明示「预分配，正式以 PLM 编码器为准」 | 否 | — |

### 2.5 检索（候选与联想，均不阻断）

| 能力 | 数据来源 | 触发 | 输出 |
|---|---|---|---|
| 规格分段补全 | 物料快照 + `param-standard.json` | 规格框输入 ≥2 字符 | `{param, unit, prefix, options[]}` + 输入框 ghost 续写 + Tab/Enter |
| 同型号系列 | `/api/new-material/spec-suggest`（3130） | 规格输入 | 系列内规格 + 库存/型号段 |
| 存量联想 | `/api/plm/suggest`（3100） | 名称/规格输入 | 存量写法（`rankStockNames`） |
| 相似型号 | `/api/new-material/similar-models` | 规格输入 | 同系列相近规格 |
| 现有库存 | `plmStock`（PLM ERPService） | 规格输入 | 数量/组织 |
| 名称同义词 | `name-synonyms`（exact/contains/prefix） | 名称输入 | 标准名建议 |
| 选型助手 | `/api/plm/select*`（3100，按小类隔离） | 打开选型助手 | 系列/型号清单 |

### 2.6 查重（`queryDuplicates`，按小类隔离）

| 等级 | 判据 | 强度 | 默认处理 | 开关 |
|---|---|---|---|---|
| `exact` | 归一化签名完全相同（同小类） | 最高 | **阻断**（二次确认后仍需返回 false 除非确认） | `dupExact` |
| `sep` | 仅分隔符差异（`looseSignature`；`/` 与空格、`-` 与空格等） | 高 | **阻断** | `dupSep` |
| `spec` | 仅规格完全相同、名称不同 | 高 | 提示（一物多号） | — |
| `order` | 参数顺序不同（`orderSignature` 排序后相同） | 高 | **阻断**（用户确认「不是同一物料」可继续） | `dupOrder` |
| `fuzzy` | token 集合 Jaccard ≥ **0.8** 且型号段相同 | 中 | 提示（疑似相似） | — |
| `none` | 该小类无索引桶 | — | 放行 | — |

离线聚类（`dedup.js`，供存量清洗，不参与录入）：
`exact`（一物多号候选，含高/低置信）、`sepOnly`（仅分隔符差异）、`sameNumber`（一号多物，多组织分发）、`fuzzy`（近重，可选）。

### 2.7 提示（warning / suggestion，不阻断保存）

| 类型 | 示例 | 来源 |
|---|---|---|
| 名称同义词 | 「空气开关」建议改为「微型断路器」 | `name-synonyms.json` |
| 命名范式 | 小类范式字段与示例、GB/T 前缀 | `naming-guide.json` |
| 名称含型号/数字 | 「名称里不要写型号/数字」 | `material-rules.detectNameModel` |
| 乘号/单位/符号 | `×` → `*`；`mm²` → `mm^2`；直径用 `Φ` | `spec.js` / `spec-symbols.json` |
| 规格补全候选 | 型号段/极数/额定电流候选 | `spec-complete` |
| 疑似重复（spec/fuzzy） | 相似物料清单 | `queryDuplicates` |
| 主要参数截断 | 「>100 字符已按上限写入 FLSXHB」 | 插件日志 |
| 编码顺延 | 「预分配 2251 → 实际 2252」 | `server.js` 提交 |

### 2.8 阻断（error，阻止保存/提交）

| 类别 | 阻断项 | 开关 key |
|---|---|---|
| 名称 | 空 | `nameEmpty` |
| 名称 | 过短/过长（2–24） | `nameLen` |
| 名称 | 全角字母数字 | `nameFullWidth` |
| 名称 | 禁止字符 | `nameForbidChars` |
| 名称 | 名称 = 规格 | `nameEqualsSpec` |
| 名称 | 禁止模式 | `nameForbidPattern` |
| 名称 | 小类不匹配 | `subMismatch` |
| 规格 | 空 | `specEmpty` |
| 规格 | 过短/过长（2–500） | `specLen` |
| 规格 | 全角 | `specFullWidth` |
| 规格 | 无字母/数字 | `specAlnum` |
| 规格 | 禁止模式 | `specForbidPattern` |
| 规格 | 占位内容 | `specPlaceholder` |
| 查重 | exact | `dupExact` |
| 查重 | sep | `dupSep` |
| 查重 | order | `dupOrder` |
| 其他 | 主要参数 >1000（看板提交） | —（硬限制） |
| 其他 | 规格宽度 >500（插件保存前） | —（`strictWidth`） |

**开关语义**（`src/block-gate.js`）：`blocks.<key> === false` → 该条 error **降级为 warning**（不阻断）；未提供或非 `false` → 保持阻断。开关共 **16 个**（13 个名称/规格 + 3 个查重）。

### 2.9 合规

| 维度 | 要求 | 校验位置 |
|---|---|---|
| 命名范式 | 名称 = 实物名（小类标准词），不写型号/参数/材质/品牌/项目 | `material-rules.json` + `naming-guide.json` |
| 国标前缀 | 范式要求 GB/T 前缀的品类必须带（如紧固件） | `naming-guide.json` |
| 字符规范 | 规格半角；`mm^2` / `Φ` / `m^3`；乘号 `*` | `spec.js` + `spec-symbols.json` |
| 单位规范 | 小类单位约定（台/个/米…） | `classification-map.json` / `settings.json` |
| 字段宽度 | ECODE 100 / ENAME 200 / GGXH 500 / ZYCS 1000 / FLSXHB 100 | PLM 元数据 + 插件 `ctlLimit` |
| 编码归属 | 正式编码由 PLM 编码器分配；看板仅「预分配」 | 流程约定（蓝图第二章补充） |
| 数据落库 | 主要参数最终写 ZYCS；载体 FLSXHB 仅中转 | 插件 2.25+ / 平台 finish |
| 权限合规 | 删除仅管理员；写操作按角色功能点；操作留痕 | `src/auth.js` + `data/audit/` |

## 五、一句话总结

> **类别决定归属，名称决定「是什么」，规格决定「是哪一款」，检索负责「别写错」，查重负责「别重复」，提示负责「更规范」，阻断负责「不能错」，合规负责「能落库、能检索、能追责」。**
