# 规格型号字符标准（单位符号统一）

- 生成时间：2026-11-16 09:48:33
- 适用范围：物料「型号规格 / 技术参数 / 主要参数」等文本字段
- 兼容底线：**GBK / CP936**，并要求在 Windows、Excel、金蝶 PLM、AutoCAD 四端一致
- 配置位置：`src/config/spec-symbols.json`（改后需重启服务）

## 一、平方/立方：统一为 `mm^2`（关键决策）

三种写法的实测对比：

| 写法 | Windows | Excel | PLM(NVARCHAR) | CAD(SHX字形) | 国标 |
|---|---|---|---|---|---|
| `mm²` | ✅ | ✅ | ✅ | ❌ 显示为 ? | ✅ 规范 |
| `mm^2` | ✅ | ✅ | ✅ | ✅ | ⚠️ 排版受限替代 |
| `mm2` | ✅ | ✅ | ✅ | ✅ | ❌ 会被读成「毫米×2」 |

**国标依据**

| 标准 | 条款要点 |
|---|---|
| GB 3100-1993《国际单位制及其应用》 | 单位符号用正体；单位符号必须作为整体使用，不得拆开 |
| GB 3101-1993 3.2.2 | 组合单位相除写作 `m/s` 或 `m·s⁻¹` —— **幂以上标表达** |
| GB 3101-1993 3.2.3 | 词头与单位符号构成的新单位符号「可以取正数或负数幂」 |
| GB 3102.1-1993 | 面积单位为 `m²`，导出单位 `mm²`（边长 1mm 的正方形面积） |

即：国标要求幂用上标（`mm²`），`mm2` 不符规范。

**为什么最终选 `mm^2`**

1. CAD 的 SHX 字形（hztxt.shx 等）只覆盖 GBK 双字节，**不含上标 ²**，图纸上 `mm²` 会显示为 `?`；
2. CAD 与 PLM 里**现行写法就是 `mm^2`**，硬改成 `mm²` 会造成图纸与系统数据不一致；
3. `mm^2` 是纯 ASCII，四端全通，且 `^` 明确表示幂，语义与国标一致（属排版受限时的技术变通写法）；
4. `mm2` 排除：会被读成「毫米 × 2」，语义不成立。

## 六、落地方式

1. **建议写法 `suggestSpec`**：
   - `6mm²` / `6mm2` / `6MM2` / `25m㎡` / `1.5㎜2` → **`6mm^2` / `25mm^2` / `1.5mm^2`**
   - `∅20` → `Φ20`；`200ºC` → `200°C`；`耐压1140∨` → `耐压1140V`
2. **录入校验 `checkSpec`**（不阻断）：
   - `含 GBK/CP936 不支持的字符（Excel/PLM/CAD 间会乱码）：∅→Φ`
   - `字符写法应统一：²→^2、㎜→mm、∨→V`
3. **单位大小写表**（`material-rules.spec.unitCase`）：`mm² / MM² / mm2 / MM2 / mm^2 / m㎡` 一律 → **`mm^2`**
4. **范式库**：13 处模板/示例已改为 `mm^2`（101601、101606、101809、110301、110302、120203 等）

## 七、修掉的一个隐藏缺陷

`unitCase` 里原有 `mm^ → mm^2` 规则（本意补全残缺写法），其右边界 `(?![A-Za-z])` 对正确的 `mm^2` 同样成立
（`^` 后是数字 `2`，不是字母），导致 `6mm^2` 被改写成 `6mm^22`。已删除该规则。

## 八、未处理与边界

- **不改存量数据**：151 + 226 条只做提示与建议，实际修改需在 PLM 内逐条确认或批量替换后复核。
- **不参与查重签名**：`normalize()` 未改，查重簇数保持 541 不变；统一只作用于「建议写法」与「校验提示」两层。
- **西里尔/希腊混形字符**（`DС` 的 С U+0421、`DQM-II/Ι` 的 Ι U+0399）：视觉与拉丁字母相同，无法可靠区分笔误与原文，需人工判断。

## 九、维护

- 调整字符：改 `spec-symbols.json` 的 `replace` / `alias` / `whitelist`，然后**重启服务**。
- 判定方法：先用 CP936 往返测试看是否可表示、是变问号还是降级，再判断语义是否唯一。
