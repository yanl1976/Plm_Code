# 中类识别与提取规则设计（初步版 · 待完善）

> 本文件是**人工可编辑的设计文档**，是 `dedup-rules.json`（识别+提取 token）与 `spec-fields.json`（每个 token 的取值正则）的“源”。
> 确认后由 AI 翻译进这两个程序配置文件（程序启动即按它们执行）。
> 设计日期：2026-10-12，基线版本 v13（2026-10-12 更新）。

## 零、已确认并落地的策略（v13）

1. **解码器定位 = 校验层，禁止反推**（`spec-fields.json` 顶层 `decoderFill:false`）
   - `model-semantics.json` / `brand-decode.json` 不再对**空参数**做“填空式反推”（如 `NSX400N` 不再反推出 `额定电流=400`、`分断能力=50`；`LC1D` 不再反推 `电流=9`）。解码器仍运行产出 `features` 供校验/可解释；如需恢复兜底填空，置 `decoderFill:true`。
2. **只提显式书写的 token**：参数值须是规格文本里**显式写出**的量（`400V`/`3P`/`50Hz`/`MIC2.0`/`C1A` 的 C 曲线）；型号代号夹带的额定值不反推。
3. **新增参数 `频率`（Hz）**：已加入断路器/接触器/继电器/电抗器/互感器(变压器/变送器/仪器仪表)/信号器件/熔断器/保护器等电气中类的 `tokens`。
4. **参数排列顺序**：`spec-fields.json` 顶层新增 `order` 数组（型号→电压→电流→极数→频率→等级→脱扣器→分断能力→…），`extractParams` 按此全局排序输出，未知参数追加末尾。
5. **抗干扰归一**（`struct-spec.js`）：规格里干扰分隔符 `_` `\` 先归一成空格（**不影响** `-` 内部的 `BVR-500V`、型号内的 `/`）；型号正则跳过前置中文/中文标点，遇 `_ \` 断词，模型内部保留 `- / .`。
   - 例：`塑壳断路器 NSX400N MIC2.0 400V 3P 50Hz` 与 `NSX400N_MIC2.0_400V_3P_50Hz` 均正确提取为 型号=NSX400N / 400V / 3P / 50Hz / MIC2.0。

## 一、总则

### 1.1 识别机制（两层）
- **主识别**：`FNUMBER` 前 6 位 → `classification-map.json` **确定性映射**到中类（编码前缀不可靠时回退小类名）。这是已落地的硬映射，无需靠名称猜。
- **辅识别**：中类名称关键字兜底（`dedup-rules.json` 的 `match` 数组）。
- 当前数据中实际出现 **29 个中类名**（含 9 条垃圾前缀归 `?`）。本设计聚焦 **20 个可结构化的核心中类**，其余作兜底。

### 1.2 提取配置（两层）
- 第一层 `dedup-rules.json`：**某中类提取哪些 token**（heuristics）。
- 第二层 `spec-fields.json`：**每个 token 怎么取值**（library 的正则 patterns / join / 单位 / 契约）。

### 1.3 单位铁律（全局，重点）
把参数值分两类：
- **量值型（带单位）**：值 = 数值 + 单位；单位**保留源文写法、仅归一化记号、绝不补原文没有的单位**。
  - 例：截面 `2.5^2mm` → `2.5mm²`；`1²mm` → `1mm²`；`2.5mm` → `2.5mm`。
  - 例：源文无单位（如 `YCW 3*25+1*16`）→ **不补**，得 `25+16`。
- **标识型（枚举/型号）**：型号、材质、颜色、极数、位数、标准、头型、脱扣曲线等，按枚举归一化，不处理单位。
- **记号归一化**（只改写法，不改语义）：
  - `mm2` / `mm²` / `²mm` / `^2mm` / `²` → `mm²`；普通 `mm` 保留 `mm`。
  - `μf` / `uf` → `μF`；`KΩ` / `kΩ` 统一 `kΩ`；`KV` → `kV`；`* × x X` → `×`。

### 1.4 提取优先级（避免误抓）
1. 专属记号（端子前缀 `UT/MC/…`、`N*X` 芯数截面、品牌内嵌额定电流）。
2. 通用“数字 + 单位”。
3. 兜底：型号取规格首词。

## 二、参数分类表（全局）

| 类别 | 参数 | 说明 |
|---|---|---|
| **量值型（保留单位）** | 额定电压、额定电流、截面、直径、螺纹、长度、尺寸(宽*深*高)、功率、阻值、容值、电感量、电抗率(Uk%)、变比、间距、量程、绝缘等级 | 值必须保留源文单位，仅归一化记号 |
| **标识型（枚举/型号）** | 型号、材质、颜色、极数、位数、品牌、标准、头型、表面处理、脱扣曲线、结构形式、线圈电压、分断能力、脱扣器 | 按枚举归一化，不补单位 |

> 注：`线圈电压`（如 `AC220V`）、`分断能力`（如 `kA`）虽含单位，但语义上是“型号/规格标识的一部分”，暂归标识型；如需作为独立量值提取可另议。
